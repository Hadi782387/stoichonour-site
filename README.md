# Stoic Honour: Gallery & Blog (@stoichonour)

React + Vite. Poster gallery (9:16, dark chiaroscuro style), blog, and a Publish page that
generates the Instagram caption (paragraph, CTA, @stoichonour credit, keywords, #Stoic #Stoicism hashtags).

## Run
npm install
npm run dev

## Content
Sample posts live in `src/data.js`. Posts published on the site are saved in the browser (localStorage).

## Deploy
Vercel: import the repo and click Deploy.
